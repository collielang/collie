# c05 · 作用域与遮蔽

裸块级作用域、多层变量遮蔽、块内无声明赋值修改外层、for 循环变量隔离、函数参数遮蔽全局、函数读取全局、const 被块内变量遮蔽、引用类型遮蔽。

## 实测结论

- 遮蔽语义与主流词法作用域一致：内层声明遮蔽外层，块结束恢复。
- **const 可以被内层块的普通变量遮蔽**（`LIMIT = 60` 是新声明而非改写，外层 const 值不变）。
- for 头部声明的 `i` 的作用域限于循环，循环结束后可重新声明同名变量。
- 函数体访问全局变量可读（`readGlobal`），形参与全局同名时优先形参。

## 陷阱备忘

- `base`/`word` 等保留字不可用作变量名；本例函数名用 `double_`（`double` 虽未见报错，但 draft.md 将其列为未来数字类型，避让为宜）。
