# b06 · 统计分析

均值、中位数（奇偶两情形）、众数（O(n²) 双循环，无 Map 时的写法）、极差（负索引取尾）、总体方差；含单元素边界。

## 状态：✅ 可运行

## 陷阱备忘

- 众数需要 `Map` 计数才能 O(n)，当前无 Map（⛔），示例用双层循环 —— Map 落地后此处是天然的重构对照点。
- 语义分析限制（同 b03）：`data[j] == current` 会被拒，需先取到 `number` 变量再比较。
