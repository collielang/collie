# d03 · 数组读写压测

固定 100 元素数组上的伪随机步进读写（线性同余取索引），共 10 万次写入；再做 1000 次 100 元素数组的深度相等（`==`）比较；全部带校验和验证。

## 状态：✅ 可运行

## 负载参数

顶部 `const number ROUNDS = 10000`（每轮 10 次写入，共 ROUNDS×10 次）。

## 实测量级

- 总耗时 **≈ 0.12 秒**（10 万次「读旧值 + 写回」+ 1000 次深度相等比较）。
- 校验和正确：`写入总数 = 100000`（所有槽位增量之和恰为写入次数）。
- 深度相等 1000/1000 全部命中，说明元素级复制后 `==` 逐元素比较稳定。

## 已知限制（写法层面）

- 数组无 push/动态扩容，尺寸只能靠字面量书写 —— 本例用两段 100 个 `0` 的字面量。
- `buf[idx] = buf[idx] + 1` 中读侧仍需先落 `number old = buf[idx];` 再写回（数组元素直接参与比较/复合表达式受语义分析限制，见 b03）。
