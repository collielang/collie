# d04 · 函数调用开销压测

小函数海量调用（无参 20 万次 + 三参 20 万次）与深递归求和（5000 层），全部带校验和验证。量化树遍历解释器中「新环境帧 + 参数绑定」的调用成本。

## 状态：✅ 可运行

## 负载参数

顶部 `CALLS = 200000`、`REC_DEPTH = 5000`（须低于 c04 探明的 6500~8000 崩溃线）。

## 实测量级

- 总耗时 **≈ 1.5 秒**（40 万次函数调用 + 5000 层递归），吞吐约 **27 万次调用/秒**。
- 对比 d01（纯循环约 200 万次迭代/秒）：**一次函数调用 ≈ 7 倍循环体开销**，是解释器最显著的热点，优化（环境帧池化/字节码 VM）应优先针对此处。
- 校验和全部正确：`200000 / 1200000 / 12502500`。
