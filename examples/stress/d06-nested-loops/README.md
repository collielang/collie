# d06 · 嵌套循环组合复杂度

四路负载：O(n²) 双层循环（100 万次内层体）、O(n³) 三层循环（51.2 万次）、深层嵌套中 break/continue 的层级语义验证、二维数组全扫描（4×4 × 10000 遍）。

## 状态：✅ 可运行

## 负载参数（防挂死换算表）

- `N2 = 1000` → 内层体执行 N2² = 100 万次；调到 3000 约 900 万次 ≈ 5 秒。
- `N3 = 80` → 内层体 N3³ = 51.2 万次；调到 200 即 800 万次，**三层循环自身开销高于双层**，慎调。

## 实测量级

- 总耗时 **≈ 1.2 秒**（合计约 170 万次内层体 + 16 万次二维索引），与 d01 吞吐基准（约 200 万次迭代/秒）吻合 —— 嵌套本身无额外劣化，开销与总迭代次数线性相关。
- break/continue 在深层嵌套中只作用于所在层，语义正确（2500 = 每轮 25 次 × 100 轮）。
- 二维索引 `grid[i][j]` 16 万次读取全部正确（总和 1360000）。
- 校验和全部正确：`1000000 / 512000 / 2500 / 1360000`。

## 陷阱备忘

- 二维元素参与累加仍需先落局部变量：`number cell = grid[i][j];`（同 b03 限制）。
